# Python desde cero

Este módulo es el punto de partida para aprender programación aplicada a Ciencia de Datos. Los ejemplos usan únicamente Python estándar; no necesitas instalar paquetes adicionales.

## Requisitos

- Python 3 instalado.
- Visual Studio Code.
- Extensión oficial de Python para VS Code (opcional, pero recomendable).

Comprueba la instalación desde la terminal:

```powershell
python --version
```

Si Windows no reconoce `python`, prueba:

```powershell
py --version
```

## Lecciones

1. [Variables, tipos de datos y operaciones](01_variables.py)
2. [Condicionales](02_condicionales.py)
3. [Ciclos](03_ciclos.py)
4. [Funciones](04_funciones.py)

## Cómo ejecutar un ejercicio

Abre la carpeta del repositorio en VS Code. Abre una terminal en la carpeta del proyecto y ejecuta, por ejemplo:

```powershell
python programacion/python/01_variables.py
```

En Windows también puedes usar `py` en lugar de `python`.

## Método de estudio

1. Lee los comentarios del archivo.
2. Ejecuta el programa sin modificarlo.
3. Cambia un dato y vuelve a ejecutarlo.
4. Resuelve el reto al final de cada lección.
5. Anota qué aprendiste y qué error corregiste.

No avances memorizando: intenta explicar con tus propias palabras qué hace cada instrucción.
