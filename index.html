PROYECTO INTEGRADOR

Analiza mercados y tianguis

Usa un problema de la Ciudad de México para conectar programación, limpieza, estadística y visualización.

PREGUNTA DE INVESTIGACIÓN

¿Cómo se distribuyen los mercados y tianguis registrados entre las alcaldías?

Trabaja únicamente con registros de una fuente identificable. Antes de concluir, revisa su cobertura, fecha, definiciones y posibles duplicados.

Datos Abiertos CDMX ↗INEGI · Datos abiertos ↗Datos.gob.mx ↗

Entregables del proyecto

  1. Datos originalesArchivo descargado y fuente documentada.
  2. Datos limpiosReglas de limpieza y duplicados justificados.
  3. Análisis reproducibleCódigo Python o SQL para obtener resultados.
  4. VisualizaciónTabla o gráfica con etiquetas y unidades.
  5. ConclusionesHallazgos, limitaciones y preguntas nuevas.
Importante: el número de filas no necesariamente representa el número real de establecimientos. Documenta la fuente y no extrapoles más allá de lo que los datos permiten.
